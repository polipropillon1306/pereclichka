# Telegram Bot — "Перекличка" с интеграцией Google Таблиц

Бот для автоматических ежедневных перекличек в групповом чате с проверкой утренней активности участников и выгрузкой в Google Таблицу.

## 🚀 Как работает бот

1. **Ежедневный опрос в 20:00 (по МСК)**:
   - Бот автоматически отправляет опрос *"Кто завтра будет на работе / в офисе?"* с кнопками `👍 Буду (+)` и `👎 Не буду (-)`.
   - Целевая дата всегда устанавливается на следующий день (завтра).
   - Участники также могут просто написать `+` или `-` в чат.
   - Опрос автоматически обновляется в чате при каждом ответе.

2. **Утренняя проверка (с 06:00 до 11:00 по МСК)**:
   - Если участник поставил `+` (будет) и написал любое сообщение в рабочий чат с 06:00 до 11:00 по Московскому времени, бот фиксирует его приход ✅.
   - В **11:00** бот автоматически проверяет список обещанных участников. Всех, кто не написал ни одного сообщения с 6 до 11 утра, бот тегает в чате со словами: *@username, вы отписались, что будете сегодня, но пока ничего не писали в чат. Вы пришли / будете сегодня?*

3. **Синхронизация с Google Таблицами**:
   - Все ответы (`+`, `-`) и статус утреннего прихода автоматически заносятся в Google Таблицу по столбцам (Датам).

4. **Права доступа**:
   - Команды управления (`/start_poll`, `/setup_sheet`) доступны только пользователям, указанным в `ADMIN_IDS` в файле `.env`.

## 🛠️ Инструкция по настройке Google Таблицы

Для того чтобы бот заносил ответы в Google Таблицу:

### Шаг 1: Создание Service Account в Google Cloud
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (например, `Telegram-RollCall`).
3. В меню выберите **APIs & Services > Library** и включите два API:
   - **Google Sheets API**
   - **Google Drive API**
4. Перейдите в **APIs & Services > Credentials** -> Нажмите **Create Credentials** -> **Service Account**.
5. Заполните название аккаунта и нажмите **Create and Continue**, затем **Done**.
6. Нажмите на созданный сервис-аккаунт, перейдите во вкладку **Keys** -> **Add Key** -> **Create new key** -> выберите **JSON**.
7. Файл ключа скачается на ваш компьютер. Переименуйте его в `service_account.json` и положите в папку с ботом (`/home/n/pereclichka/service_account.json`).

### Шаг 2: Доступ к вашей Google Таблице
1. Откройте файл `service_account.json` и найдите там значение поля `"client_email"` (выглядит как `something@project.iam.gserviceaccount.com`).
2. Откройте нужную Google Таблицу и нажмите кнопку **Поделиться** (Share).
3. Вставьте этот e-mail и предоставьте права **Редактор** (Editor).
4. Скопируйте ссылку на таблицу (URL).

### Шаг 3: Привязка таблицы к Telegram чату
1. Добавьте бота в ваш рабочий чат и дайте ему права администратора (чтобы он мог закреплять сообщения).
2. Напишите в чате команду:
   ```text
   /setup_sheet https://docs.google.com/spreadsheets/d/ВАШ_ИДЕНТИФИКАТОР/edit
   ```

## 💻 Запуск бота

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Файл конфигурации `.env`
Создайте файл `.env` на основе примера `.env.example`:
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
POLL_TIME=20:00
CHECK_TIME=11:00
ADMIN_IDS=123456789,987654321
ALLOWED_CHAT_IDS=-1001234567890
```

### 3. Запуск
```bash
./venv/bin/python main.py
```

---

## 📌 Команды в чате

- `/start` — Инициализация бота в чате.
- `/start_poll` — Запустить опрос переклички на завтра вручную (только для пользователей из ADMIN_IDS).
- `/setup_sheet <URL>` — Привязать Google Таблицу к текущему чату (только для пользователей из ADMIN_IDS).
